## 📱 Features

- 🔐 **Authentication** — Email/password + Google Sign-In via Firebase Auth
- 💬 **Private Messaging** — One-to-one real-time chat (WhatsApp style)
- 🖼️ **Image Sharing** — Send photos in chat using Base64 encoding
- 🔔 **Push Notifications** — FCM notifications for new messages (Android)
- 🟢 **Online Presence** — Live online/offline status for every user
- ✍️ **Typing Indicator** — Animated dots when the other user is typing
- 📊 **Analytics** — Custom event tracking with Firebase Analytics
- 💥 **Crash Reporting** — Automatic error capture with Firebase Crashlytics
- 🔒 **Secure Rules** — Firestore security rules per conversation room
- ⏱️ **Timestamps** — Message time shown on every bubble

## 🚀 Getting Started

### Prerequisites

- [Flutter SDK](https://flutter.dev/docs/get-started/install)
- [Android Studio](https://developer.android.com/studio) with an emulator (API 33+)
- A free [Firebase account](https://console.firebase.google.com)

### Installation

**1. Clone the repo**
```bash
git clone https://github.com/yourusername/flutter_chat_app.git
cd flutter_chat_app
```

**2. Install FlutterFire CLI**
```bash
dart pub global activate flutterfire_cli
```

**3. Create a Firebase project**

Go to [console.firebase.google.com](https://console.firebase.google.com) → Create project → Enable these services:
- Authentication → Email/Password + Google
- Firestore Database → Start in test mode
- Cloud Messaging (automatic)
- Crashlytics → Enable

**4. Connect Flutter to Firebase**
```bash
flutterfire configure
```
Select your project and platforms. This auto-generates `lib/firebase_options.dart`.

**5. Install dependencies**
```bash
flutter pub get
```

**6. Run the app**
```bash
# Android emulator
flutter run -d emulator-5554

# Windows
flutter run -d windows
```

## 🔐 Firestore Security Rules

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    match /messages/{messageId} {
      allow read, write: if request.auth != null;
    }

    match /users/{userId} {
      allow read: if request.auth != null;
      allow write: if request.auth != null && request.auth.uid == userId;
    }

    match /typing/{docId} {
      allow read, write: if request.auth != null;
    }

    match /chats/{roomId} {
      allow read, write: if request.auth != null &&
        request.auth.uid in resource.data.participants;

      match /messages/{messageId} {
        allow read, write: if request.auth != null;
      }
    }
  }
}
```

## 🗄️ Firestore Data Model

```
firestore/
├── users/
│   └── {uid}/
│       ├── email
│       ├── isOnline
│       ├── fcmToken
│       └── lastSeen
│
├── chats/
│   └── {uid1_uid2}/              ← sorted UIDs joined with _
│       ├── participants: [uid1, uid2]
│       ├── lastMessage
│       ├── lastTime
│       └── messages/
│           └── {messageId}/
│               ├── type           ← "text" or "image"
│               ├── text
│               ├── imageBase64
│               ├── senderId
│               ├── senderEmail
│               └── timestamp
│
└── typing/
    └── {roomId_uid}/
        ├── isTyping
        ├── uid
        └── roomId
```

## 📸 How Private Chat Rooms Work

Each private conversation gets a unique room ID generated by **sorting and joining both user UIDs**:

```dart
String get _roomId {
  final ids = [currentUserId, receiverId]..sort();
  return ids.join('_');
}
```

This guarantees that user A chatting with user B, and user B chatting with user A, always land in the **same Firestore document** — with no duplicates.
